# immersive-sea-life
Projection mapped sea life animations.

**Live demo:** https://zrecore.github.io/immersive-sea-life/ (add `?autostart=1` to skip the start screen)

## Development

`npm install`, then `npm run dev`. See `CLAUDE.md` for architecture notes.
